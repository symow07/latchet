September. Nothing was lost — it was moved. Work from this path, and get it off an iCloud-managed
folder (see §5, item 1).

### 1a. Why the typecheck took ten minutes

It passes, but it took about ten minutes, where it took under one in September. The most likely
cause — not confirmed — is that the folder is iCloud-backed: macOS evicts files it considers idle
and downloads them again on first read, so a full typecheck would page hundreds of source files
back in. If so, every build pays the same cost until the project is on a local disk. A second
reason for §5, item 1.

### What "working" means in this document

**Working in code, tested, and never run on a phone.** That is the honest status of almost
everything below. The newest build that exists is from **26 August** (`00f35e33`), it predates the
business-mode auth fix and the whole redesign, and no device build has ever been produced (only
simulator builds — see `SUBMISSION.md §5`). So the right reading of every ✅ here is "the code is
right and the tests say so", not "a user has seen it work".

### `main` and `origin/main` have diverged — harmlessly, but it blocks pushing

`git status` reports `ahead 140, behind 140`. The two tips have **the identical tree**
(`3d96c5a8…` on both) and the same messages; the only difference is the author email. The
remote's history was rewritten to replace `mr.oumaali@gmail.com` with the GitHub `noreply`
address, so the commits have new hashes and share no merge base with the local ones.

**No content is unpushed.** But a plain `git push` from this machine will be rejected. The fix
that keeps the uncommitted redesign intact is `git fetch && git reset --soft origin/main` — check
`git diff --stat HEAD origin/main` is empty first. Do not `--hard` reset: that deletes the redesign.

## 5. What it takes to ship

In order. Items 1–4 are things only you can do; most of what's after is small.

1. **Protect the work.** Copy this folder somewhere iCloud doesn't manage, then commit the
   redesign: `git fetch && git reset --soft origin/main`, then commit. Until this is done, the
   entire redesign exists in one place.
2. **Configure production.** Check the Railway dashboard for `OPENAI_API_KEY`; set a real one.
   Without it the advisor, receipts, PDF import and business advisor all fail — which is
   everything Pro sells. Rotate the Railway token while you're there.
3. **Buy `latchet.app`.** Unblocks the support email, the Resend domain and privacy hosting — <!-- TODO(domain) -->
   three blockers, one purchase.
4. **Create the store products** in App Store Connect and Play Console, under a RevenueCat
   entitlement named `pro`. The paywall has nothing to sell until then.
5. **Password reset.** The one missing piece of code that is a genuine launch blocker. Needs the
   Resend key from item 3. While the email path is being built, decide whether to finish email
   verification (the screen exists) or delete it.
6. **Run the live advisor tests** — `RUN_LIVE_AI_TESTS=1` with the real key. Do not ship the
   health-data tier until the three refusal tests pass. This is what turns a safety design into a
   safety claim.
7. **Fix the three dark-mode inversion bugs** and **restore an entry point to Connect a bank**
   (or decide to hide it until Plaid production lands — but decide it, rather than lose it).
8. **Delete the dead weight in §4.** Especially Skia, before the first device build.
9. **Make a device build and walk every screen** — business mode above all, which has never
   worked on any build that exists. Face ID, notifications, Siri, the share sheet and voice all
   need hardware.
10. **Store metadata and screenshots.**

### Should do, before or just after launch

- Tests for the health score and the five untested behaviour detectors — both put numbers in
  front of users with nothing pinning them.
- Offline support for bill reminders, recurring, net worth and category budgets, or stop calling
  the app offline-first.
- One read of the Arabic by a native speaker.

### Not needed for v1

Everything in §3.8 except password reset. The welcome screen and glass quick actions are design
choices, not gaps a reviewer will reject. Plaid production can follow launch.
